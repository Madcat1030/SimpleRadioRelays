# 0.2.1 diagnostic findings

The four added regressions were run against the released 0.2.0 implementation before changing production code. The normal native two-channel bridge and packet delivery during Relay reload passed. Three regressions failed: a same-quality path selected an exhausted carrier for the wired bridge; a missed mast notification never refreshed the antenna score; repeated dirty notifications kept restarting antenna settling.

The 0.2.0 XML is retained as `validation/0.2.1/reproduced-on-0.2.0.xml`. The fixed run retains all previous tests and adds those four fixtures. Native Simple Radio failures are compared separately with an addon-disabled control.

Changes are limited to the final delivery tie-break in `RelayRouter` and maintenance scheduling in `RelayBlockEntity`. Numeric RF equations, graph edge construction, frame deduplication, encoded payload handling, block IDs, inventory/NBT formats, saved-network filename, client models and rendering remain unchanged from 0.2.0.

The packet bridge uses a real native receiver block, transmitter block and copper wire at C, owner-backed handheld routing at A, and a saved unloaded B relay. It captures routed synthetic encoded data before speaker decoding. It proves packet reachability, carrier power, inherited interference and continued delivery during CHECK; it does not itself listen to multiplayer audio.
